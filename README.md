Comparative data analysis project focused on the short-term rental markets of Zurich and Milan. The repository combines a reproducible Python cleaning pipeline with a Tableau dashboard deliverable to turn raw listing exports into an analysis-ready dataset for exploratory, geographic, and pricing comparisons.

## Why this project exists

Public short-term rental data is often noisy: missing prices, inconsistent review fields, extreme outliers, and city-level extracts that are difficult to compare directly. This project standardises two city datasets into a single cleaned source so pricing, availability, review intensity, and neighbourhood dynamics can be analysed with less manual effort and better traceability.

## Project highlights

- Reproducible data cleaning workflow implemented in Python instead of notebook-only logic.
- Safer preprocessing choices for portfolio publication: no hard-coded local paths, no secrets, and no brittle one-off transformations.
- Clean repository structure separating raw data, processed data, source code, notebook exploration, and Tableau assets.
- Packaged Tableau workbook for visual storytelling on top of the cleaned dataset.

## Main features

- Merge and standardise listing exports from Zurich and Milan.
- Impute missing prices using median values at neighbourhood level with city fallback.
- Replace missing `reviews_per_month` values with `0.0` when listings have no review activity.
- Cap unrealistic long-stay and high-end outlier values to keep downstream analysis readable.
- Preserve a ready-to-open Tableau workbook for visual exploration.

## Data processing rules

The cleaning pipeline applies a small set of explicit, reviewable rules:

1. Add a `city` field to each source dataset before merging.
2. Remove low-value text fields that are not required for the comparison dataset.
3. Parse `last_review` as a date and expose `last_review_year` for easier aggregation.
4. Impute missing prices with the median price of the same city and neighbourhood.
5. Fill missing `reviews_per_month` values with `0.0`, which matches the dataset semantics when a listing has no reviews.
6. Clip extreme values per city for `price`, `reviews_per_month`, and `number_of_reviews_ltm`, and cap `minimum_nights` at 365.

## Getting started

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
cd projet_visualisations_data
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

macOS / Linux:

```bash
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
pip install -e .
```

### 4. Rebuild the cleaned dataset

```bash
python scripts/build_dataset.py
```

The generated file is written to `data/processed/zurich_milan_listings_clean.csv`.

### 5. Run the tests

```bash
python -m unittest discover -s tests
```

### 6. Open the dashboard

Open `tableau/zurich_milan_market_analysis.twbx` in Tableau Desktop or Tableau Public to explore the visual layer of the project.

## Analysis assets

- `data/raw/`: original source extracts used by the pipeline.

- `notebooks/exploratory_cleaning.ipynb`: lightweight notebook for quick inspection and experimentation.
- `tableau/zurich_milan_market_analysis.twbx`: packaged workbook containing the dashboard assets.
